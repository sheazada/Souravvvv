The ERP now supports visibility layers for:
- owner decision-making
- operations monitoring
- dispatch supervision
- finance follow-up
- retailer self-view
- driver self-view

This means your system now covers not only transactions, but also reporting and management visibility.

## Important implementation notes
- dashboards and reports are aggregation-first API responses
- PDF/Excel rendering is still not directly generated by these endpoints; they provide structured payloads for future export formatting
- some KPIs use simplified thresholds (for example low stock) and can later be moved into settings/product-level rules
- accounting-driven reports use the transaction base already implemented
