Local Run & Boot Guide (How to Boot on Your Machine)

You can launch the complete production multi-stage setup or run the development servers directly on your local terminal.

# 1. Quick Production Multi-Stage Docker Boot (PostgreSQL 17 + NestJS + Next.js)
git clone https://github.com/sheazada/Souravvvv.git
cd Souravvvv && docker compose -f docker-compose.prod.yml up --build -d
docker compose -f docker-compose.prod.yml exec backend node scripts/prepare-prisma-test-db.js
# Backend API available at http://localhost:3001 | Frontend PWA at http://localhost:3000
# 2. Running Local Development & Verification Suites
# Run 158+ Live PostgreSQL Backend E2E Tests:
cd backend && export TEST_DATABASE_URL="postgresql://postgres:postgres@localhost:5432/dairy_erp_test" && npm run test:ci:local
# Run 81 Frontend Vitest UI Component Suites & Typecheck:
cd frontend && bash ../scripts/run-frontend-ui-suites.sh
